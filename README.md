# Convergence Codex V4 — Public Website (GitHub Pages)

A mobile-friendly Convergence: Phoenix Rising encyclopedia using the pre-existing server lore and gameplay documentation.

## First deployment / upgrade from V3

1. Extract this ZIP.
2. Upload **the contents** of this folder (not the enclosing folder itself) to the root of your GitHub Pages repository.
3. Include `.nojekyll`, `index.html`, `assets/`, `races/`, `universal/`, and the other top-level HTML pages.
4. Commit changes to the Pages publishing branch.
5. Open your normal `https://<username>.github.io/<repository>/` link. No custom domain is required.

Visitor theme choices are saved on the visitor's device using browser localStorage when available.

## Editing the live Codex

Sign in with Discord and use **Edit Mode** in the top bar. The Convergence Owner role (ID `1100315883773112432`) grants publishing access. Select **Edit content** to edit entries, page text and themes. In **Worlds**, open a location and choose **Lore**, **Location Guild(s)** or **Mystical Items** to edit those records in place. Readers can open shared links directly to any listed guild or item.

Published edits live in PhoenixCore’s persistent database. GitHub Pages supplies the site and the original Codex archive. Routine editing and new location entries take effect when readers reload the page. The theme picker includes 30 presets and remembers each reader’s choice.

## PhoenixCore character sheets

Open **PhoenixCore** in the main navigation to browse Discord players and their character cards. Choose **New Submission** for characters, techniques, items, races, transformations, OC updates or training. The practice dashboard lets you try player submission, staff judgment and owner review. The live service sends approvals to the owner in Discord. [Dashboard](phoenixcore/index.html) · [Bot and dashboard setup](phoenixcore-service/README.md)
